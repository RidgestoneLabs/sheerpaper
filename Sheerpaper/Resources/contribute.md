# Contributing to Sheerpaper

Sheerpaper is open source, and contributions are welcome. It is based on MacDown, which was built by Tzu-ping Chung and a community of contributors.

If you are reading this, then you are probably curious or want to contribute in some way. Read on to see how you can do so.

## Getting the Source Code

Sheerpaper is hosted on GitHub:

https://github.com/RidgestoneLabs/sheerpaper

Here you can get the source code, read through the issues and start contributing.

## But, I am not a Coder

Contribution is not limited to software developers, since there are other ways you can help. For example, contributing towards documentation, translation and support. Open an issue or a pull request on GitHub to get started.
